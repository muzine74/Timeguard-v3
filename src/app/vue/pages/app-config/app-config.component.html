Courriels reçus (Microsoft 365)

TimeGuard lit la boîte de courriel de l'entreprise toutes les cinq minutes. Quand un courriel reçu vient d'une adresse présente dans les contacts d'une compagnie, il est ajouté à l'historique de cette compagnie, dans Communications (« Courriel reçu »). Les autres courriels ne sont ni copiés ni conservés. La boîte n'est jamais modifiée. Les identifiants viennent d'une application inscrite dans Microsoft Entra, avec la permission d'application Mail.Read de Microsoft Graph (voir l'Aide).
